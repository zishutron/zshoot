    Install in
    three steps

    ZShoot is shared as an APK file, so Android asks one extra question the first time.

    1. Download

      Tap Download APK. The file comes from the official ZShoot release page on GitHub and is about 17.6 MB.

    2. Allow the install

      Open the file. If Android blocks it, tap Settings and allow installs from your browser or file manager.

    3. Launch and play

      Tap Install, then Open. Turn your phone sideways and start your first wave.
